1. Watch the pods come up:
   kubectl get pods -n {{ .Release.Namespace }} -w

2. Access the API via minikube NodePort:
   minikube service {{ include "contoso.fullname" . }}-api -n {{ .Release.Namespace }}

3. Test the endpoints:
   curl http://<service-url>/health
   curl http://<service-url>/dbtest
   curl http://<service-url>/logs

4. Check the HPA status (requires metrics-server):
   kubectl get hpa -n {{ .Release.Namespace }}
